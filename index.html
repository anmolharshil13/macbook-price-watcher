iPhone notifications setup (ntfy)
  1. Install ntfy from the App Store and allow notifications.
  2. Tap + and subscribe to a long, random topic name (e.g. mbp-watch-7f3k9q2x). Anyone who knows it can read it.
  3. In the GitHub repo: Settings → Secrets and variables → Actions → New secret NTFY_TOPIC = that name.
  4. Tap Test push above. You should get a notification within a minute.
